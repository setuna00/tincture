# tag 中文译名：规则

给 Danbooru tag 起中文名，用在一个 NovelAI prompt 编辑器里：tag chip 上英文旁边的灰色小字、补全列表、中文 / 拼音搜索。用的人是中文圈画 AI 图的人。
译名表是我们自己翻的，以后有新 tag 要补译也照这份规则来。

## 输入 / 输出
- 输入每行：`英文<TAB>作品数`；角色 / 作品多两列：`<TAB>Danbooru 上的其他名字<TAB>社区译名`（没有就空着）。
- 输出每行：`英文<TAB>中文`。**和输入同样的顺序、同样的行数，英文原样照抄**（括号、符号、大小写都不改）。不要表头、不要注释、不要空行。

## 怎么起名
1. 简体中文，短：名词短语或动作短语，2–8 个字最好。不解释、不加句号、不加引号。
2. 用中文圈常用的叫法（AI 绘图社区、ACG 圈的说法）；没有常用叫法就翻成自然的中文。
3. 意思以 Danbooru 的定义为准，不按字面猜：cowboy shot = 七分身；staff (music) = 五线谱；1girl = 1个女孩（不是「单人」）；hand up = 举起一只手；stretching = 伸懒腰。
4. 括号里的限定词：只是消歧的（`canopy (aircraft)`）不写进中文；是内容的一部分就保留，用全角括号：`yuzuki roa (1st costume)` → 梦月罗亚（初始服装）；`xxx (cosplay)` → 中文名（cosplay）；`xxx (style)` → xxx画风。
5. 同一类词写法统一，**和 `glossary.tsv`（现在界面上用的 600 个）保持一致**：
   - `X hair` → X发（long hair 长发、blue hair 蓝发）；`X eyes` → X眼（blue eyes 蓝眼、pink eyes 粉眼）
   - `X background` → X色背景；`holding X` → 拿着X；`X print` → X图案；`frilled X` → 荷叶边X；`X-trimmed X` → X边X；`see-through X` → 透视X；`X focus` → X特写
   - 颜色 + 物品：常用的写短的（白衬衫、黑裙子），其他写「蓝色X」
6. 颜文字（tag 名本身是颜文字 / 字符画的：:d、x3、^_^、>_<、=_=、\o/、uu~）：写颜文字原样（照 tag 的小写、下划线）+ 全角「（表情）」：x3 → x3（表情）、^_^ → ^_^（表情）；名字里的英文词照翻（double \m/ → 双手\m/（表情））。想让意思也能搜到，写进 `search-alt.tsv`（只进搜索）。
   符号（!?、...、^^^、+++）不算颜文字：写它表示的东西（感叹问号、省略号、惊吓线）。
7. 性相关的 tag 照实、中性地翻（这是图像标签数据），不委婉、不加评价。
8. 专有名词（角色、作品、人名、品牌、游戏里的东西、武器型号）：用官方或通行的中文名。给了「其他名字」时以它为依据，日文汉字名转成简体（輿水幸子 → 舆水幸子、北条加蓮 → 北条加莲）；「社区译名」只作参考，可能有错。**拿不准就留空**（`英文<TAB>`，后面什么都不写），界面会显示英文——错的中文名比没有更糟，不要音译瞎编。
9. 角色只写名字，不加作品名（`ganyu (genshin impact)` → 甘雨）；同一作品里有同名、或者是换装 / cosplay 才加全角括号。
10. 作品名用通行的中文译名，没有就保留原文（Re:CREATORS、MOTHER 1）。
11. Danbooru 元信息（commentary、bad id、md5 mismatch 这类）照字面简短翻（评论、无效 ID、MD5 不匹配）。
