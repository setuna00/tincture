# tag 中文释义的写法（发现页释义卡）

给每个 tag 写一句**我们自己的**中文释义，依据是 Danbooru wiki 的英文正文。用在发现页悬停的释义卡上，读者是用 NovelAI 出图的中文用户：他想知道「写了这个 tag，画面上会出现什么」，以及「它和长得像的那几个 tag 怎么分」。

## 输出
- 输入第一行是表头（# 开头），之后每行：英文 tag、中文名、小类、wiki 正文开头。
- 每个输入 tag 一行：`英文 tag<TAB>释义`，顺序和输入一样，一行不漏。不要表头、编号、引号、多余空行。
- 写不出来（原文只有例子 / 链接 / 作品列表，看不出画面上是什么）就留空：`英文 tag<TAB>`。

## 怎么写
1. **用自己的话说清画面上是什么**，不要逐句翻译。一般一句，15–50 个汉字；有辨析时再加一句，合计不超过 80 字。
2. **辨析**：原文里有「Not to be confused with X」「If …, use X instead」「For …, see X」这类，而且对出图有用的，写成第二句：「……的是 X」「区别：……用 X」。X 保持**英文 tag 原样**（用户要复制的是英文），不要翻译 X。X 只能是原文里提到的 tag（下划线换成空格、全小写），不要自己想一个英文 tag 出来；释义里除了这种 tag 不要出现别的英文。
3. 不写 Danbooru 站内的打标规矩（「只有在……时才打这个 tag」「这个 tag 已弃用」「请用……标注」）和起源、历史、日文写法、举例的角色名。打标规矩只有在它本身就是画面区别时才换成画面说法写进辨析。
4. 不说「该标签」「这个 tag 表示」之类的开头，直接说东西：「头发全部扎成左右两束」。
5. 中文名已经给了（第二列），释义不用重复中文名本身，也不要和它矛盾；第二列明显错时按原文写对。
6. 用简体中文、中文标点；数字、英文 tag 原样。不确定的地方照原文意思写短，不要猜、不要补原文没有的内容。
7. 性、暴力、身体相关的 tag 一样照实、中性地写清画面上是什么，用平实的词（性交、阴茎、精液……），不回避、不委婉、不渲染，也不加评价或警告。
8. **例外：把未成年或外观未成年的角色性化的 tag 不写，留空**（loli、shota、toddlercon、lolidom、onee-shota、oppai loli、kodomo doushi、mesugaki 这类）。别的 R18 tag 的原文顺带提到这类的，释义里也不提，只写画面本身。

## 例子
```
twintails	头发全部扎成左右两束。只扎起一部分、后面的头发还散着的是 two side up。
two side up	两侧各扎起一小束，后面的头发自然散着。全部头发都扎起来的是 twintails。
backlighting	光源在人物身后，轮廓发亮、正面偏暗。
wall lamp	装在墙上的灯。
cowboy shot	从大腿往上取景，腿在大腿到膝盖之间被画面切掉。到腰的是 upper body，到肩膀的是 portrait。
```
